# ข้อมูลอ้างอิง (src/data)

| โฟลเดอร์ | เนื้อหา | แหล่งที่มา |
|---|---|---|
| `thaiAddress/areas.json` | จังหวัด → อำเภอ → ตำบล + รหัสไปรษณีย์ (77 จังหวัด, 7,436 ตำบล) | ThepExcel-Thailand-Tambon (https://github.com/ThepExcel/download) — ผู้ดูแลระบุว่าเว็บ ThepExcel อนุญาตให้นำไปใช้ฟรี (ใน GitHub ไม่มีไฟล์ license) |
| `thaiAddress/villages.json` | หมู่บ้าน/ชุมชน (เฉพาะอุตรดิตถ์ 644 และกระบี่ 403) | ศูนย์ข้อมูลเปิด DOPA https://catalog.dopa.go.th (ยังไม่ได้ตรวจเงื่อนไขการใช้งาน) |
| `schools/<รหัสจังหวัด>.json` | โรงเรียนในสังกัด สพฐ. 29,642 แห่ง (ไม่รวมเอกชน/สังกัดอื่น) | ไฟล์ทะเบียนโรงเรียนที่ผู้ดูแลระบบจัดหามา (ยังไม่ระบุแหล่ง/สัญญาอนุญาต) |

สร้างใหม่ด้วย `scripts/buildThaiAddressData.ts` และ `scripts/buildSchoolData.ts` (ไม่รันกับระบบจริง; อ่านไฟล์ต้นทางในเครื่องเท่านั้น)

รายการที่ผู้ดูแลแก้/เพิ่ม/ซ่อน เก็บใน Firestore คอลเลกชัน `reference_schools` และ `reference_villages`
(doc id `b_<รหัสชุดหลัก>` = แก้/ซ่อนชุดหลัก, `c_…` = เพิ่มเอง; ลบ doc = คืนค่าเดิม) จัดการที่เมนูแอดมิน "รายชื่อหมู่บ้าน / รายชื่อโรงเรียน"
