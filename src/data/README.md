# ข้อมูลอ้างอิง (src/data)

| โฟลเดอร์ | เนื้อหา | แหล่งที่มา / เงื่อนไขการใช้ (ตรวจเมื่อ 12 ต.ค. 2569) |
|---|---|---|
| `thaiAddress/areas.json` | จังหวัด → อำเภอ → ตำบล + รหัสไปรษณีย์ (77 จังหวัด, 7,436 ตำบล) | ThepExcel Thailand Tambon Database โดย ศิระ เอกบุตร — https://www.thepexcel.com/thailand-tambon-database/ ผู้จัดทำระบุว่า "เอาข้อมูลนี้ไปใช้ได้เลย ไม่ต้องขออนุญาต" (ไม่ได้ระบุสัญญาอนุญาตทางการ ไม่พูดถึงการใช้เชิงพาณิชย์/การอ้างอิง) และระบุว่าไม่ใช่ฐานข้อมูลทางการ อาจมีข้อผิดพลาด |
| `thaiAddress/villages.json` | หมู่บ้าน/ชุมชน (เฉพาะอุตรดิตถ์ 644 และกระบี่ 403) | กรมการปกครอง (DOPA) ผ่านศูนย์ข้อมูลเปิด https://catalog.dopa.go.th/dataset/11 — สัญญาอนุญาต "Open Data Common", ระดับชั้นข้อมูล "เปิดเผย", เงื่อนไขการเข้าถึง "ไม่มีการจำกัดการเข้าถึงข้อมูล", หมวดข้อมูลสาธารณะ |
| `schools/<รหัสจังหวัด>.json` | โรงเรียนในสังกัด สพฐ. 29,642 แห่ง (ไม่รวมเอกชน/สังกัดอื่น) | สำนักงานคณะกรรมการการศึกษาขั้นพื้นฐาน (สพฐ.) สำนักนโยบายและแผนการศึกษาขั้นพื้นฐาน — https://opendata.obec.go.th/dataset/obec-school-007 (ชุดข้อมูลปีการศึกษา 2563 ปรับปรุง 30 เม.ย. 2564) สัญญาอนุญาต "Open Data Common" · **ข้อควรทราบ:** ข้อมูลเก่า (ปี 2563) โรงเรียนที่ยุบ/ตั้งใหม่/เปลี่ยนชื่อหลังจากนั้นอาจไม่ตรง — แอดมินแก้/เพิ่ม/ซ่อนได้ที่เมนู "รายชื่อโรงเรียน" และไฟล์ที่ใช้ในแอปเป็นไฟล์ที่ผู้ดูแลระบบจัดหา (ยังไม่ได้เทียบกับไฟล์ทางการ 1:1) |

สร้างใหม่ด้วย `scripts/buildThaiAddressData.ts` และ `scripts/buildSchoolData.ts` (ไม่รันกับระบบจริง; อ่านไฟล์ต้นทางในเครื่องเท่านั้น)

รายการที่ผู้ดูแลแก้/เพิ่ม/ซ่อน เก็บใน Firestore คอลเลกชัน `reference_schools` และ `reference_villages`
(doc id `b_<รหัสชุดหลัก>` = แก้/ซ่อนชุดหลัก, `c_…` = เพิ่มเอง; ลบ doc = คืนค่าเดิม) จัดการที่เมนูแอดมิน "รายชื่อหมู่บ้าน / รายชื่อโรงเรียน"
